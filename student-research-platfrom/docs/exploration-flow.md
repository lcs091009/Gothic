# 선택하며 이어가는 탐구

- 초기 활동 분석은 서로 다른 탐구 방향 3개와 선택 가능한 준비 방법을 제안한다. 수행이나 시작 시점을 강요하지 않는다.
- R/T 번호는 서버가 인증된 조회 순서의 활동·자료 제목으로 치환해 표시한다. 알 수 없는 번호는 근거 확인 필요로 표시한다.
- 분석 작업실의 ‘탐구 주제 고르기’는 별도 앱 화면으로 전환한다. 주제·후속 질문 선택마다 기존 화면을 교체하며 설명을 아래에 계속 누적하지 않는다.
- 이전 질문으로 돌아가면 이미 받은 선택지를 재사용한다. 학생이 직접 질문을 입력할 수도 있다. 화면을 닫거나 새로고침하면 심화 경로는 초기화된다.
- 각 질문 생성은 기존 /api/analyze 인증·학생 역할·기록 소유권·자료 수신자 검증·분산 요청 제한을 거친다. 브라우저의 활동 내용은 근거로 신뢰하지 않는다.
- 요청은 최근 질문 12개, 각 400자 이내로 제한한다. 응답은 2~4개 선택지의 형식·길이·중복을 검증한다. 선택 경로는 수행 결과로 간주하지 않는다.
- 잘못된 응답은 다시 시도할 수 있으며 자동 재요청하지 않는다. 화면을 떠나면 요청을 중단하고 늦은 응답을 무시한다. 기존 45초 공급자 제한과 410 대체 모델 처리를 유지한다.
- 선생님 첨부파일은 이름·안내만 참고하며 파일 본문을 읽지 않는다.

검증: API 및 파서 테스트, 기존 전체 테스트, 린트, 프로덕션 빌드, 서버 렌더링으로 선택 카드·직접 질문·화면 진입 표시 확인. 실제 NVIDIA 출력 품질과 로그인 상태의 브라우저 클릭 흐름은 이 환경에서 검증하지 않았다.
