# 과목별 심화탐구

학생 화면에서 활동 흐름 분석 → 과목별 심화탐구로 이동합니다. 등록한 선택과목, 선택 활동의 과목, 주요 과목을 보여 주며 다른 과목 이름도 직접 입력할 수 있습니다.

과목을 고른 뒤 주제 제안받기를 누르면 선택 과목의 개념과 실제 활동의 연관성을 설명하는 주제를 제안합니다. 해당 과목의 활동이 없어도 선택할 수 있지만 근거가 부족한 부분은 명시하도록 안내합니다. 여러 과목 연결을 선택하면 기존 통합 탐구 흐름을 사용합니다.

선택한 과목은 모든 후속 요청에 전달됩니다. 주제를 고른 뒤에는 같은 주제에서 깊이 연결을 설명합니다. 과목을 변경하면 탐구 경로가 초기화되고 새 선택지를 요청할 수 있습니다. 생성 중에는 과목 변경을 막으며 이전 선택/취소로 요청을 중단할 수 있습니다.

과목 선택만으로 AI를 호출하지 않습니다. 주제 생성과 후속 설명은 기존 요청 한도와 2분 제한을 적용합니다. 과목 이름은 80자까지 서버에서 검증하며 사용자 메시지의 데이터로 전달합니다. 활동과 교사 자료는 기존 서버 권한 검증으로 조회합니다. 데이터베이스 및 배포 환경변수 변경은 필요 없습니다.
