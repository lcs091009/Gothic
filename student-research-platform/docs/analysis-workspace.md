# 학생 분석 자료 선택과 전용 화면

학생은 전달받은 선생님 첨부를 파일별로 선택한다. 기본은 선택 없음이며 최대 8개 과제·20개 첨부를 선택할 수 있다. 서버는 현재 학생 이메일로 조회하고 선택한 과제 ID와 첨부 ID가 실제 자료에 있는지 확인한다. 다른 학생의 자료, 삭제된 첨부, 중복·과도한 선택은 AI 호출 및 할당량 소비 전에 거부한다. 브라우저가 보낸 자료 내용은 신뢰하지 않는다.

선택 자료는 파일명과 저장된 선생님 안내로 분석에 반영한다. PDF·Docs·Sheets의 본문을 읽거나 OCR하지 않는다. 자료 확인 영역과 결과 화면에 이 한계를 표시하며 AI에도 bodyAvailable=false를 제공한다. 본문에서 참고할 내용은 학생이 보충 입력에 직접 적을 수 있다.

분석 버튼을 누르면 앱 내 전용 분석 작업실 화면으로 이동한다. 왼쪽 항목 이동과 중앙 분석 내용을 분리하고, 선택한 활동·과목·자료 연결 카드, 실제 과목별 활동 개수 막대, 선택 활동의 기록 목록을 표시한다. 생성 중 화면과 실패·재시도·자료 선택으로 돌아가기를 제공한다. 결과를 만든 당시의 선택 자료를 별도로 보관해 선택 변경 후 이전 결과를 다시 봐도 근거가 섞이지 않는다. 화면을 나가면 브라우저 요청을 취소하지만 이미 시작된 서버 AI 요청과 할당량은 되돌리지 않는다.

수치 시각화는 실제 선택한 기록 개수만 사용하며 임의 역량 점수나 합격 가능성을 만들지 않는다. 텍스트는 React 텍스트 노드로 출력하고 제공자 HTML을 실행하지 않는다. 모바일 단일 열, 키보드 포커스, 움직임 줄이기를 지원한다.
