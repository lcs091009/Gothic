# 자료를 읽고 한 주제로 이어가는 탐구

학생의 활동 분석 화면에서 활동 기록·학생 첨부·선생님 첨부를 선택합니다. 과목 기준은 `AI가 과목 추천` 또는 `과목 직접 선택` 두 가지입니다. 직접 선택은 과목 드롭다운과 다른 과목 입력으로 구성하며 과목 버튼을 나열하지 않습니다. 선생님 자료만으로도 분석할 수 있습니다.

선택한 첨부를 학생의 Google 계정 권한으로 브라우저에서 읽습니다. PDF는 PDF.js 워커로 페이지별 텍스트를 읽고, Google 문서/슬라이드는 텍스트로, Google 시트는 XLSX로 내보내 모든 워크시트 셀을 읽습니다. DOCX·PPTX·XLSX는 이미지 항목을 풀지 않고 문서 XML의 텍스트를 읽습니다. TXT·CSV·MD·JSON도 지원합니다. 한글 PDF에 필요한 CMap·글꼴 파일은 배포 번들에 포함됩니다.

읽기 권한이 부족하면 분석 화면 안의 Picker에서 같은 파일을 다시 선택해 앱 접근을 허용할 수 있습니다. 이 Picker는 활동 등록 첨부와 입력을 변경하지 않습니다. 파일을 못 읽으면 AI를 호출하기 전에 파일별 이유를 보여주며, 재시도하거나 읽은 자료만 사용하기를 학생이 선택합니다. 파일 본문이 없는 자료를 읽었다고 설명하지 않습니다.

이미지·스캔 PDF의 OCR, 이미지 속 도표·수식의 시각 해석, HWP/HWPX, 영상·음성 분석은 구현하지 않았습니다. 텍스트가 없는 PDF 페이지 수와 읽지 못한 파일을 표시합니다. Google 내보내기 제한·조직 정책·암호화 파일은 Google 또는 파일 형식에서 제한될 수 있습니다.

총 첨부 500MB 제한은 유지하며 파일 수를 20개로 제한하지 않습니다. PDF는 범위 다운로드와 페이지 순회로 메모리 사용을 줄입니다. 안전상 파일당 최대 200만 자의 추출 텍스트를 보관하고 요청 전체 본문은 50만 자로 나누어 발췌합니다. AI 컨텍스트에는 자료 전체에 걸친 발췌와 선택 과목·질문과 연결되는 발췌를 총 6만 자까지, 파일당 1.2만 자까지 반영합니다. 전체 원문을 그대로 모두 AI에 전달했다고 표시하지 않으며 발췌 여부를 공개합니다. 읽기부터 AI 응답까지 기존 클라이언트 2분 제한을 적용하므로 실제 500MB·대량 페이지 처리 완료 시간은 기기·네트워크에 따라 달라집니다.

서버는 본문 파일 ID를 인증된 사용자의 선택 활동 첨부·본인에게 전달된 선생님 첨부에 대조합니다. 다른 학생의 파일이나 선택하지 않은 파일 본문은 AI 요청 전에 거부합니다. 본문은 브라우저가 읽어 전달한 참고자료로 취급하며 교사 평가·승인·수행 사실로 사용하지 않습니다. 원문·Drive 토큰을 로그나 데이터베이스에 저장하지 않습니다. Google 토큰은 Google API 호출에만 쓰며 AI 서버에 보내지 않습니다. 계정 변경 시 분석 컴포넌트를 새로 만들어 자료 상태를 분리합니다.

처음에는 실제 자료의 근거·교과·탐구 질문을 묶어 주제를 추천합니다. 학생이 고른 첫 질문을 중심 주제로 유지합니다. 이후에는 새 주제 목록을 숨기고 현재 단계의 가이드라인을 제공합니다. 준비할 것·진행 중 점검·결과 해석·탐구 정리 중 학생이 필요한 단계나 실제 진행 상황을 입력합니다. 조건·방법·결과를 대신 확정하지 않습니다.

응답은 초기 분석/주제와 후속 가이드를 구분합니다. JSON 앞뒤 문장·글자 수 차이·누락 보조 항목·중복 선택지·문자열 내부 줄바꿈·마지막 쉼표를 복구합니다. 충분한 일반 설명은 그대로 보여줍니다. 완전히 잘리거나 비어 있는 응답, 인증·네트워크·공급자 오류를 항상 성공으로 처리하지는 않습니다. 선택 경로와 자료를 보존하고 이유와 재시도를 제공합니다. 자동으로 추가 유료 AI 요청을 반복하지 않습니다.

SQL·환경변수·OAuth 범위 추가는 필요 없습니다. 기존 Google Drive/Picker 설정과 파일의 학생 읽기 권한이 필요합니다. Node 22.13 이상으로 빌드합니다.

## 화면 전환과 재시도

분석 화면·작업실·탐구 가이드는 처음 열 때 생성하고 메뉴 이동 시 숨겨 보관합니다. 다른 화면에 있는 동안 요청이 완료되어도 돌아오면 같은 결과와 선택 경로를 보여줍니다. 계정별 key로 상태를 분리하고 로그아웃/계정 변경 시 기존 화면을 제거합니다. 같은 계정의 로그인 정보 재발행이나 브라우저 탭 복귀는 학생 자료를 초기화하지 않습니다. BFCache 복귀 시 기존 세션이 있으면 전체 앱을 로딩 화면으로 교체하지 않습니다. 브라우저 새로고침·탭 종료 후 복구는 이 변경에 포함하지 않습니다.

AI 재시도에 실패해도 직전 완료 결과와 탐구 경로를 지우지 않습니다. 동일한 첨부의 성공한 본문 읽기는 최대 10분간 컴포넌트 메모리에서 재사용하여 재시도 때 반복 다운로드하지 않습니다. 본문이 변경되었다면 분석 참고 정보의 `첨부 본문을 다시 읽고 분석`을 사용합니다. 첫 분석은 핵심 근거와 주제 중심으로 분량을 줄이고 현재 단계와 실제 경과 시간을 표시합니다. 실제 NVIDIA 지연을 측정하거나 0건의 오류를 보장한 변경은 아닙니다.
