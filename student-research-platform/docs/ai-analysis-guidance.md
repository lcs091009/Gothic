## 이 서비스가 구성한 탐구 보완 기준

동기·질문, 교과 개념, 설계·자료 수집·분석, 결과와 근거, 한계와 개선, 본인의 역할·협업·피드백, 성찰·후속 질문을 점검한다. 이는 공식 지침에 나열된 모든 활동의 의무 기재 항목이 아니라, 위 원칙을 학생의 탐구 계획과 성찰에 적용하기 위해 구성한 점검 기준이다. 인문·사회·독서와 실험 탐구에는 각각 적절한 방법을 사용한다.

답변은 핵심 흐름 / 교과 연결 / 다음 탐구 / 기록 보완과 바로 할 일의 4개 항목을 유지하며, 충분한 자료가 있으면 1,600~2,400자 내외를 목표로 한다. 자료가 적으면 더 짧게 작성한다. 설명은 활동의 근거 → 판단의 이유 → 한계와 개선 방법을 연결한다. 교과 연결마다 개념의 쉬운 뜻과 적용할 새 질문을 설명하고, 대표 후속 탐구 1개의 실행 순서·비교 기준·분석 방법·기간·산출물을 구체적으로 제안한다. 보완 사항은 실제 기록에서 빠진 핵심 최대 3개를 우선순위대로 안내한다. 문단은 요점 하나를 2~4문장으로 설명하며 같은 내용을 반복하거나 소제목·표·중첩 목록을 늘리지 않는다.

응답 토큰 상한은 2,600에서 4,200으로 늘렸다. 모델, 입력 자료의 상한, 45초 요청 제한, 호출/할당량 정책은 동일하다. 토큰 상한은 최대 생성량이며 목표 분량이나 실제 답변 품질을 보장하지 않는다. 답변이 길어지면 생성 시간과 사용량이 늘 수 있다. 기존에 표시된 분석은 자동 재생성되지 않으며 새 분석 요청에 적용된다.

규정 변경 시 공식 자료를 다시 확인해야 한다. 프롬프트와 렌더링 검증은 모델 답변 품질을 입증하는 평가가 아니므로, 배포 후 실제 활동 자료로 내용 누락·근거 오류·분량을 확인한다.
