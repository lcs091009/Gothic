# 활동 분석 처리 범위와 시간

- 선택 개요는 최대 48개, 본문 발췌는 최대 20개. 활동을 20개 이하 선택하면 각 기록의 본문이 모두 분석 입력에 포함된다. 긴 본문은 기록별 2,000자 이내로 앞과 끝을 발췌한다.
- 초기 분석의 답변 한도는 6,400토큰이다. 심화 질문은 기존 4,200토큰을 유지한다. 답변 한도를 늘린다고 제공자의 처리 속도가 빨라지는 것은 아니다.
- 서버는 인증·DB 조회·분산 요청 한도 확인·NVIDIA 요청·응답 읽기에 하나의 115초 마감 시간을 공유한다. 외부 요청에는 취소 신호를 전달하며, 응답하지 않는 작업도 마감 시간이 지나면 504로 종료한다. 410 대체 모델도 시간을 새로 받지 않는다.
- 화면은 로그인 상태 확인부터 120초에 요청을 중단하고 선택과 질문 경로를 유지한다. 대기 상태와 요청 잠금을 해제하여 다시 시도할 수 있게 한다. 중단된 응답은 새 요청을 덮어쓰지 않는다.
- Vercel api/analyze.js 실행 한도는 120초로 설정한다. Hobby에서 120초를 사용하려면 Fluid compute가 켜져 있어야 한다. 배포 환경의 실제 설정은 저장소에서 확인할 수 없다.
- NVIDIA 혼잡·네트워크 지연이 있으면 시간 안에 분석 성공을 보장할 수 없다. 실제 제공자를 대상으로 20개 활동의 응답 시간을 측정하지 않았다.

공식 배포 설정: https://vercel.com/docs/functions/configuring-functions/duration
